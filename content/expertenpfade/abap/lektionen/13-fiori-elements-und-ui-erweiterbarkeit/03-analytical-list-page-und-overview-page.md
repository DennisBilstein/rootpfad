# Analytical List Page & Overview Page

*Fiori Elements & UI-Erweiterbarkeit · ca. 6 Min.*

Neben List Report/Object Page gibt es die **Analytical List Page (ALP)** — kombiniert Diagramme mit einer filterbaren Tabelle für Analyse-Szenarien. Die **Overview Page (OVP)** bündelt mehrere Kacheln unterschiedlicher Datenquellen zu einem rollenbasierten Dashboard — typisch für Startseiten im Fiori Launchpad.

> **Tipp:** Die Wahl des richtigen Fiori-Elements-App-Typs ist selbst schon eine Architekturentscheidung — sie folgt der Frage "Was ist die primäre Nutzungsabsicht: bearbeiten, analysieren oder überblicken?", nicht der verfügbaren Datenmenge.

## Kontrollfragen

**1. Wofür ist die Analytical List Page (ALP) primär gedacht?**

- [x] Analyse-Szenarien mit Diagrammen kombiniert mit einer filterbaren Tabelle
- [ ] Reine Stammdatenpflege
- [ ] Berechtigungsverwaltung

*Erklärung:* ALP verbindet visuelle Analyse (Charts) mit tabellarischer Detailsicht.

**2. Wofür wird typischerweise eine Overview Page (OVP) eingesetzt?**

- [x] Rollenbasierte Dashboard-Startseiten mit Kacheln aus mehreren Datenquellen
- [ ] Nur für technische Systemlogs
- [ ] Für Massendatenlöschungen

*Erklärung:* OVPs bündeln relevante Kennzahlen und Einstiege für eine Nutzerrolle auf einer Seite.
